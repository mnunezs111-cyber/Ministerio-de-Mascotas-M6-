# Registro Cívil de Mascotas

Aplicación web desarrollada con Node.js, Express, Axios y Handlebars para gestionar un registro de mascotas y sus dueños.  
Permite agregar, listar y eliminar mascotas de manera sencilla, con almacenamiento en formato JSON.

# Objetivos

- Implementar un sistema de registro de mascotas con backend en Node.js.
- Exponer una **API REST** para consumo con Axios.
- Renderizar vistas dinámicas con Handlebars.
- Manejar operaciones CRUD básicas: listar, agregar y eliminar mascotas.
- Integrar un frontend funcional con Bootstrap.
